## Real Map Implementation of DFS 🗺️

Ever wondered how algorithms like Depth-First Search (DFS) tackle real-world problems? Here's a visual breakdown of DFS in action, exploring the winding streets of Lisbon's historic Alfama district!

Depth-First Search is a graph traversal algorithm that explores as far as possible along each branch before backtracking. When faced with multiple unvisited neighbors, DFS **arbitrarily picks one and dives in**, pushing the current node onto a **stack** (either explicitly managed or implicitly through recursion). It continues this process until it hits a dead end or a previously visited node. If it hits a dead end, it **backtracks** by popping the last node from the stack and exploring its next available neighbor. This "go deep first" strategy can be incredibly efficient for finding a path or exploring all reachable nodes, though it can sometimes explore suboptimal paths if not carefully guided, and its performance is highly dependent on the graph's structure, not necessarily the shortest path.

We've transformed the intricate alleyways and intersections of Lisbon's Alfama into a graph representation. Each **intersection** serves as a **node**, and the **streets connecting them** are the **edges**. In this visualization, the **red and green lines** represent the **visited edges** as DFS explores the graph, showing its journey down various paths. The **vibrant yellow line** highlights the **computed path** – the sequence of streets the algorithm ultimately identified. Unlike a simple grid where neighbor exploration is predictable, real-world maps like Alfama present a more complex graph. The number of edges per node can vary wildly, and the "cost" of traversing an edge (travel time, distance) isn't uniform. This means DFS's speed here is about finding *a* path, not necessarily the *fastest* or *shortest* one, showcasing its inherent trade-offs in practical applications.
