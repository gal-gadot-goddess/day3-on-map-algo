**Paragraph 1: The Logic of DFS**

Depth-First Search is a graph traversal algorithm that explores as far as possible along each branch before backtracking. When DFS encounters a node, it prioritizes exploring one of its unvisited neighbors. This "go deep" strategy is typically implemented using a **stack** (either explicitly or implicitly through recursion). Unlike Breadth-First Search (BFS) which uses a queue to explore layer by layer, DFS's reliance on a stack means it can get "lost" down a lengthy path, but this often makes it significantly faster for certain problem types where finding *any* path quickly is more critical than finding the shortest. The core idea is to exhaust a single path before considering alternatives.
