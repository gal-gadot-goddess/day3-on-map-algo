**Paragraph 1: The Logic of Depth-First Search**

Depth-First Search is a graph traversal algorithm that explores as far as possible along each branch before backtracking. At each node, it prioritizes exploring one of its unvisited neighbors. This "go deep" approach often utilizes a **stack** (explicitly or implicitly through recursion) to keep track of the path taken and the nodes to revisit. Unlike Breadth-First Search (BFS) which uses a queue for level-by-level exploration, or algorithms employing priority queues for weighted paths, DFS systematically plunges into a path until it hits a dead end or has explored all reachable nodes from that branch. While this can sometimes lead it down "long and winding roads" (getting "lost" in a sense), its simplicity and speed in many scenarios make it a powerful tool for tasks like finding paths, cycle detection, or topological sorting.
